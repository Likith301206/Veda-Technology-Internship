# Handle Missing Values Using Pandas

## Veda Technology Internship — Day 22

### Project Overview

This project demonstrates how to identify and handle missing values in a dataset using Pandas.

### Objective

Learn basic data preprocessing techniques and understand how missing values can be handled before machine learning.

### Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

### Dataset

Iris Dataset

The dataset contains 150 records and 5 columns. Three missing values are introduced temporarily for demonstration.

### Tasks Completed

1. Identified missing values in each column.
2. Created a copy of the original dataset.
3. Filled missing numerical values using the median.
4. Filled missing categorical values using the mode.
5. Compared missing-value counts before and after cleaning.
6. Explained the selected treatment methods.

### Missing-Value Treatment

* **Numerical columns:** Missing values were replaced with the median because it is less sensitive to extreme values than the mean.
* **Categorical columns:** Missing values were replaced with the most frequent category (mode).

### Result

The cleaned dataset contains no missing values in the columns analyzed.

The original dataset file remains unchanged.

### Conclusion

This task demonstrates how Pandas can handle missing data and prepare a dataset for further analysis or machine learning.
