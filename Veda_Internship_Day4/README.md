# Sales Data Calculator

## Veda Technology Internship — Day 4

### Project Overview

This project is a Python-based Sales Data Calculator developed as part of the Veda Technology AI & ML Internship.

The program analyzes a list of sales values and calculates the total sales, average sales, highest sale, and lowest sale.

### Objective

The objective of this task is to practice Python lists and built-in functions for basic numerical data analysis.
