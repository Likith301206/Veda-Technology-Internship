# Student Grade Calculator

## Veda Technology Internship — Day 2

### Project Overview

This project is a Python-based Student Grade Calculator developed as part of the Veda Technology AI & ML Internship.

The program calculates grades for students based on their marks using predefined grading conditions.

### Objective

The objective of this task is to practice Python conditional statements, functions, dictionaries, loops, and input validation.

### Technologies Used

- Python
- Jupyter Notebook

### Grading Criteria

| Marks | Grade |
|---:|:---|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |
| Below 0 or Above 100 | Invalid Marks |

### Features

- Stores student names and marks using a Python dictionary.
- Calculates grades using `if`, `elif`, and `else`.
- Uses a function for grade calculation.
- Tests multiple mark values.
- Handles invalid marks below 0 or above 100.

The Student Grade Calculator successfully assigns grades based on predefined mark ranges. The program also validates marks and identifies values outside the valid range of 0 to 100.
