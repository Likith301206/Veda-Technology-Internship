# Day 26: Sales Data Visualization Using Python

## Overview

This project demonstrates how to visualize sales data using Python, Pandas, and Matplotlib.

## Objective

To analyze sales data and represent sales patterns using bar charts and line charts.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Tasks Completed

* Created a sample sales dataset.
* Analyzed total sales for different products.
* Created a bar chart to compare product sales.
* Created a line chart to visualize monthly sales trends.
* Observed sales patterns and identified the highest-sales month.

## Visualizations

### 1. Total Sales by Product

A bar chart compares the total sales of laptops, mobile phones, and tablets.

### 2. Monthly Sales Trend

A line chart displays sales trends from January through June.

## Key Findings

* Mobile phones generated the highest total sales among the three products.
* May recorded the highest monthly sales.
* Sales decreased in June compared with May.
