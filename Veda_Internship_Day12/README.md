# NumPy Array Operations

## Veda Technology Internship — Day 12

### Project Overview
This project demonstrates mathematical operations on NumPy arrays using Python.

### Objective
Understand vectorized numerical operations using NumPy.

### Technologies Used
- Python
- NumPy
- Jupyter Notebook

### Operations Performed
- Addition
- Subtraction
- Multiplication
- Division
- Checking array shapes

### Arrays Used
Array 1: [10, 20, 30, 40, 50]

Array 2: [2, 4, 5, 8, 10]

### Results

| Operation | Result |
|---|---|
| Addition | [12, 24, 35, 48, 60] |
| Subtraction | [8, 16, 25, 32, 40] |
| Multiplication | [20, 80, 150, 320, 500] |
| Division | [5, 5, 6, 5, 5] |

Both arrays have the shape `(5,)`.

### What Is Vectorization?
Vectorization allows NumPy to perform operations on entire arrays without explicitly writing loops.
