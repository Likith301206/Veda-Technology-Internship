# Dataset Exploration Using Pandas

## Veda Technology Internship — Day 17

### Project Overview
This project explores the Iris dataset using Pandas to understand its structure, dimensions, data types, and statistical characteristics.

### Objective
Understand the structure and basic characteristics of a dataset before modeling.

### Technologies Used
- Python
- Pandas
- Jupyter Notebook

### Dataset
Iris Dataset

- Total records: 150
- Total columns: 5
- Numerical columns: 4
- Categorical columns: 1
- Missing values: None observed

### Operations Performed
- Displayed the first five records using `head()`.
- Displayed the last five records using `tail()`.
- Checked dataset dimensions using `shape`.
- Identified columns using `columns`.
- Examined data types and non-null counts using `info()`.
- Generated statistical summaries using `describe()`.

### Key Observations
1. The dataset contains 150 records and 5 columns.
2. Four columns contain numerical measurements.
3. The `species` column contains categorical data.
4. All columns have 150 non-null values.
5. The dataset uses approximately 6 KB of memory.

### Files
- `Dataset_Exploration.ipynb` — Notebook containing the analysis.
- `README.md` — Project documentation.

### Conclusion
This project demonstrates how Pandas helps explore datasets and understand their structure before applying machine learning techniques.
