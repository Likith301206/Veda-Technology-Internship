# AI vs ML vs Deep Learning

## Veda Technology Internship — Day 10

### Project Overview

This project presents a comparison of Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL), including their definitions, differences, relationships, and real-world applications.

### Objective

The objective is to understand the differences between AI, ML, and Deep Learning and how these technologies are related.

### Tools Used

- Python
- Jupyter Notebook
- Markdown

### Topics Covered

- Definition of Artificial Intelligence
- Definition of Machine Learning
- Definition of Deep Learning
- Comparison of AI, ML, and Deep Learning
- Relationship between the three fields
- Real-world applications
- Summary and conclusion

### Comparison Summary

| Feature | AI | ML | Deep Learning |
|---|---|---|---|
| Scope | Broadest field | Subset of AI | Subset of ML |
| Purpose | Build intelligent systems | Learn patterns from data | Learn complex patterns using multi-layer neural networks |
| Examples | Expert systems, planning | Spam detection, recommendations | Image recognition, speech recognition |

### Relationship

Artificial Intelligence is the broad field. Machine Learning is a subset of AI, and Deep Learning is a subset of Machine Learning.

**AI ⊃ ML ⊃ Deep Learning**

### Real-World Applications

- Virtual assistants
- Email spam detection
- Image recognition
- Recommendation systems
- Autonomous vehicles
- Medical image analysis
