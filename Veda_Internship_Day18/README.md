# Select Dataset Columns Using Pandas

## Veda Technology Internship — Day 18

### Project Overview
This project demonstrates how to select specific rows and columns from a dataset using Pandas `loc` and `iloc`.

### Objective
Learn how to access specific parts of a DataFrame.

### Technologies Used
- Python
- Pandas
- Jupyter Notebook

### Dataset
Iris Dataset

The dataset contains 150 records and 5 columns.

### Operations Performed
- Loaded the Iris dataset using `pd.read_csv()`.
- Selected specific columns using `loc`.
- Selected rows using `loc`.
- Selected columns using `iloc`.
- Selected specific rows and columns using `iloc`.

### Key Concepts

**loc**
- Label-based selection.
- Uses row labels and column names.
- Includes the ending label in slices.

**iloc**
- Position-based selection.
- Uses integer positions for rows and columns.
- Excludes the ending position in slices.
