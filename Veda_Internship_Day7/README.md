# Student Information Dictionary

## Veda Technology Internship — Day 7

### Project Overview

This project is a Python-based Student Information Dictionary developed as part of the Veda Technology AI & ML Internship.

The program stores student information using a Python dictionary and performs basic operations such as searching, adding, updating, and displaying student records.

### Objective

The objective of this task is to understand how Python dictionaries can be used to store and manage structured student information using unique Student IDs.

### Technologies Used

- Python
- Jupyter Notebook

### Operations Performed

- Created student records using unique Student IDs
- Searched for a student
- Added a new student
- Updated student information
- Displayed all student records
- Tested an invalid Student ID
