# Simple Data Filtering

## Veda Technology Internship — Day 8

### Project Overview

This project demonstrates simple data filtering using Python. A collection of student records is created using lists and dictionaries, and students are filtered based on marks, age, and department.

### Objective

The objective of this task is to understand how conditions can be used to filter structured data.

### Technologies Used

- Python
- Jupyter Notebook

### Filtering Operations

The program performs the following filtering operations:

- Students with marks of 80 or above
- Students belonging to the CSE department
- Students aged 20 or below
- CSE students with marks of 80 or above
