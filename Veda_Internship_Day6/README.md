# Text Analysis

## Veda Technology Internship — Day 6

### Project Overview

This project is a Python-based Text Analysis program developed as part of the Veda Technology AI & ML Internship.

The program analyzes a given text and calculates the number of words, characters, vowels, and repeated words.

### Objective

The objective of this task is to practice Python string processing, loops, dictionaries, conditional statements, and built-in functions.

### Technologies Used

- Python
- Jupyter Notebook
