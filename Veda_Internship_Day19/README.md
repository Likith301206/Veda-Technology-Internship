# Filter Dataset Records Using Pandas

## Veda Technology Internship — Day 19

### Project Overview
This project demonstrates how to filter records from a dataset using Pandas Boolean conditions.

### Objective
Learn how to retrieve relevant records from a dataset using one or more conditions.

### Technologies Used
- Python
- Pandas
- Jupyter Notebook

### Dataset
Iris Dataset

The dataset contains 150 records and 5 columns.

### Filtering Operations
1. Selected flowers with sepal length greater than 5.
2. Selected flowers with petal length greater than 4.
3. Selected flowers satisfying both conditions.
4. Selected flowers belonging to the setosa species.

### Concepts Learned
- Boolean filtering
- Comparison operators
- Multiple conditions using `&`
- Filtering categorical data
- Counting filtered records

### Files
- `Filter_Dataset_Records.ipynb` — Notebook containing the filtering examples.
- `README.md` — Project documentation.

### Conclusion
This project demonstrates how Pandas conditions can efficiently retrieve relevant records from a dataset.
