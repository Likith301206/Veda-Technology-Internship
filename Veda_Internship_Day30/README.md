# Day 30: Exploratory Data Analysis (EDA) Using Python

## Objective

To perform exploratory data analysis on a dataset using Pandas, NumPy, and Matplotlib to identify meaningful patterns and relationships.

## Project Description

This project explores a student dataset containing study hours, attendance, and marks. It covers data inspection, cleaning, statistical analysis, visualization, and correlation analysis.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Tasks Performed

* Created a student dataset using Pandas.
* Examined the dataset structure and dimensions.
* Generated a statistical summary.
* Checked for missing values and duplicate records.
* Cleaned the dataset.
* Created four visualizations:

  1. Histogram showing the distribution of marks.
  2. Scatter plot showing study hours versus marks.
  3. Scatter plot showing attendance versus marks.
  4. Bar chart comparing marks by student.
* Generated a correlation matrix.
* Identified meaningful patterns and recorded observations.

## Key Observations

1. The dataset contains information about 10 students.
2. The average marks summarize the overall performance of the sample.
3. The highest-scoring student can be identified using the dataset.
4. Study hours and marks show a positive correlation in this sample.
5. Attendance and marks also show a positive correlation in this sample.
6. Visualizations make it easier to understand distributions and relationships.

## Conclusion

Exploratory Data Analysis helps understand a dataset before performing further analysis or building machine learning models. Data cleaning, descriptive statistics, visualizations, and correlation analysis help reveal useful patterns and potential relationships between variables.

The observed correlations do not establish cause and effect.
