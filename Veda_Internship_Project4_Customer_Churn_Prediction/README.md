# Customer Churn Prediction & Retention Analysis

## Project Overview

This project uses machine learning to predict whether customers of a subscription-based telecom service are likely to leave.

It analyzes customer demographics, service usage, contract types and billing information to understand the factors associated with customer churn.

## Objectives

* Clean and preprocess customer data.
* Perform Exploratory Data Analysis (EDA).
* Apply feature engineering and categorical encoding.
* Build machine learning classification models.
* Evaluate model performance.
* Identify important churn-related features.
* Suggest customer retention strategies.

## Dataset

IBM Telco Customer Churn Dataset.

* 7,043 customer records.
* 21 original columns.
* Target variable: Churn.
