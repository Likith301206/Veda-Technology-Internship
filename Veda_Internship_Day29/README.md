# Day 29: Relationship Analysis Using Python

## Objective

To analyze the relationship between two numerical variables using a scatter plot and understand the patterns in the data.

## Project Description

This project analyzes the relationship between students' study hours and their marks. Python libraries are used to create a dataset, visualize the relationship using a scatter plot, and calculate the correlation coefficient.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Tasks Performed

* Created a dataset containing study hours and marks.
* Displayed the dataset using Pandas.
* Created a scatter plot using Matplotlib.
* Calculated the correlation coefficient.
* Analyzed the relationship between the two variables.

## Observations

1. There is a positive relationship between study hours and marks.
2. Students who study for more hours generally score higher marks in this sample dataset.
3. The scatter plot shows a strong positive relationship between the variables.

## Conclusion

Scatter plots help visualize relationships between numerical variables. The correlation coefficient provides a numerical measure of the strength and direction of a linear relationship.

The observed relationship does not necessarily mean that study hours alone determine students' marks.
