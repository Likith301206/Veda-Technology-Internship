# Day 27: Distribution Analysis Using Python

## Overview

This project analyzes the distribution of student marks using Python, Pandas, and Matplotlib. A histogram is used to visualize how marks are distributed across different ranges.

## Objective

To understand the distribution of numerical data by examining its concentration, spread, and statistical properties.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Tasks Completed

* Created a sample student marks dataset.
* Calculated descriptive statistics using Pandas.
* Generated a histogram to visualize the distribution of marks.
* Calculated the minimum and maximum marks.
* Calculated the mean, median, and standard deviation.
* Observed the concentration and spread of student marks.

## Visualization

### Histogram of Student Marks

The histogram displays the number of students within different mark ranges.

## Statistical Analysis

* **Minimum:** Lowest mark in the dataset.
* **Maximum:** Highest mark in the dataset.
* **Mean:** Average of all student marks.
* **Median:** Middle value of the sorted marks.
* **Standard Deviation:** Measures how spread out the marks are.

## Key Observations

1. The histogram shows how student marks are distributed across different ranges.
2. The mean and median help describe the central tendency of the marks.
3. The standard deviation indicates the variation in student performance.
4. The histogram helps identify ranges containing more students.
