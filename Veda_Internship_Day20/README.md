# Sort Dataset Using Pandas

## Veda Technology Internship — Day 20

### Project Overview
This project demonstrates how to sort dataset records using Pandas in ascending and descending order.

### Objective
Understand how sorting helps organize and analyze datasets.

### Technologies Used
- Python
- Pandas
- Jupyter Notebook

### Dataset
Iris Dataset

The dataset contains 150 records and 5 columns.

### Operations Performed
1. Sorted sepal length in ascending order.
2. Sorted sepal length in descending order.
3. Sorted petal length in ascending order.
4. Sorted records using multiple columns: species and sepal length.

### Concepts Learned
- `sort_values()`
- Ascending and descending sorting
- Sorting by multiple columns
- The `ascending` parameter

### Files
- `Sort_Dataset.ipynb` — Notebook containing the sorting examples.
- `README.md` — Project documentation.

### Conclusion
This project demonstrates how Pandas sorting operations help organize data and make analysis easier.
