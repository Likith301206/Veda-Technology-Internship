# NumPy Student Marks Analysis

## Veda Technology Internship — Day 11

### Project Overview

This project analyzes student marks using NumPy and calculates important statistical measures to understand student performance.

### Objective

Learn how NumPy arrays and built-in statistical functions simplify numerical calculations.

### Technologies Used

- Python
- NumPy
- Jupyter Notebook

### Dataset

The program uses the following student marks:

`[78, 85, 92, 67, 88, 95, 73, 81, 90, 76]`

### Analysis Performed

- Calculated total marks.
- Calculated mean and median.
- Identified maximum and minimum marks.
- Calculated standard deviation.

### Results

| Statistic | Result |
|---|---:|
| Total Marks | 825 |
| Mean Marks | 82.5 |
| Median Marks | 83.0 |
| Maximum Marks | 95 |
| Minimum Marks | 67 |
| Standard Deviation | 8.50 |

### Python Concepts Used

- NumPy arrays
- `np.sum()`
- `np.mean()`
- `np.median()`
- `np.max()`
- `np.min()`
- `np.std()`

### Project Structure

- `NumPy_Student_Marks.ipynb` — Notebook containing the analysis.
- `README.md` — Project documentation.

### Conclusion

This project demonstrates how NumPy can efficiently analyze numerical data and calculate useful statistical measures.
