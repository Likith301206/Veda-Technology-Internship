# Python Data Processing

## Veda Technology Internship — Day 9

### Project Overview

This project demonstrates Python-based data processing using structured employee records. It calculates summary statistics, filters records by department, and sorts employees according to salary.

### Objective

The objective is to combine Python concepts to process structured data and generate useful statistics.

### Technologies Used

- Python
- Jupyter Notebook

### Dataset

The program uses eight employee records containing:

- Employee ID
- Employee Name
- Department
- Salary

### Operations Performed

- Created structured employee records using dictionaries and lists.
- Displayed employee information.
- Calculated average salary using a function.
- Identified the highest and lowest salaries.
- Filtered employees by department.
- Generated summary statistics.
- Sorted employees by salary from highest to lowest.
