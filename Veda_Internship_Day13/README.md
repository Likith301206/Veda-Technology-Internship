# NumPy Data Filtering

## Veda Technology Internship — Day 13

### Project Overview
This project demonstrates how to filter numerical data using NumPy conditions and Boolean indexing.

### Objective
Practice Boolean indexing and numerical filtering using NumPy.

### Technologies Used
- Python
- NumPy
- Jupyter Notebook

### Dataset
`[10, 25, 35, 50, 60, 75, 85, 100]`

### Operations Performed
- Filter values greater than 50.
- Filter values less than 50.
- Filter values equal to 50.
- Filter values greater than or equal to 60.
- Filter values less than or equal to 35.

### Results

| Condition | Filtered Values |
|---|---|
| Greater than 50 | [60, 75, 85, 100] |
| Less than 50 | [10, 25, 35] |
| Equal to 50 | [50] |
| Greater than or equal to 60 | [60, 75, 85, 100] |
| Less than or equal to 35 | [10, 25, 35] |

### Concepts Learned
- NumPy arrays
- Boolean conditions
- Boolean indexing
- Numerical data filtering

### Conclusion
This project demonstrates how NumPy Boolean indexing helps select values that satisfy specific conditions without using explicit loops.
