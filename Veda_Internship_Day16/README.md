# Load a CSV Dataset Using Pandas

## Veda Technology Internship — Day 16

### Project Overview
This project demonstrates how to load a CSV dataset using Pandas and display its first and last five records.

### Objective
Learn how to import tabular data for machine learning workflows.

### Technologies Used
- Python
- Pandas
- Jupyter Notebook

### Dataset
Iris Dataset

The dataset contains 150 records and 5 columns.

### Operations Performed
- Loaded the CSV dataset using `pd.read_csv()`.
- Displayed the first five records using `df.head()`.
- Displayed the last five records using `df.tail()`.
- Checked the dataset shape.
- Displayed column names.
- Inspected dataset information using `df.info()`.

### Dataset Columns
- sepal_length
- sepal_width
- petal_length
- petal_width
- species

### Files
- `Load_CSV_Dataset.ipynb` — Notebook containing the code.
- `iris.csv` — Dataset used for analysis.
- `README.md` — Project documentation.

### Conclusion
This project demonstrates how Pandas simplifies loading and inspecting CSV datasets for data analysis and machine learning.
