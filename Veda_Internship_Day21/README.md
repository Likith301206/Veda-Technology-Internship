# Missing Value Analysis Using Pandas

## Veda Technology Internship — Day 21

### Project Overview
This project identifies and analyzes missing values in a dataset using Pandas.

### Objective
Understand the importance of detecting missing data before performing data analysis or building machine learning models.

### Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

### Dataset
Iris Dataset

The dataset contains 150 records and 5 columns. Three missing values are introduced temporarily for demonstration.

### Operations Performed
1. Loaded the Iris dataset.
2. Introduced missing values for demonstration.
3. Counted missing values in each column.
4. Calculated the total number of missing values.
5. Calculated missing-value percentages.
6. Created a missing-value summary.
7. Identified columns requiring treatment.

### Concepts Learned
- `isnull()`
- `sum()`
- Missing-value percentages
- Data quality analysis
- Identifying columns requiring treatment

### Files
- `Missing_Value_Analysis.ipynb` — Notebook containing the analysis.
- `README.md` — Project documentation.

### Conclusion
This project demonstrates how Pandas can identify missing data and summarize its distribution, an important step in preparing datasets for machine learning.
