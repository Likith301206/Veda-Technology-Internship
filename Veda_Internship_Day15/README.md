# NumPy Statistical Analysis

## Veda Technology Internship — Day 14

### Project Overview
This project analyzes a numerical dataset using NumPy statistical functions to understand data distribution and identify unusually high or low values.

### Objective
Practice applying statistical functions to numerical data.

### Technologies Used
- Python
- NumPy
- Jupyter Notebook

### Dataset
`[45, 60, 72, 85, 90, 55, 78, 95, 68, 82]`

### Statistical Calculations
- Mean
- Median
- Standard deviation
- Minimum value
- Maximum value

### Results

| Statistic | Result |
|---|---:|
| Mean | 73.0 |
| Median | 75.0 |
| Standard Deviation | 15.10 approximately |
| Minimum | 45 |
| Maximum | 95 |

### Additional Analysis
- Compared the mean and median.
- Identified values greater than 85.
- Identified values less than 50.

### Concepts Learned
- NumPy statistical functions
- Numerical data analysis
- Boolean indexing
- Data distribution

### Conclusion
This project demonstrates how NumPy statistical functions help summarize numerical data and identify values that meet specific conditions.
